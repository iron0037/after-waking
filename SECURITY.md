# Security policy

After Waking runs entirely in your browser. It has no server, no accounts and no online features, and your save stays in your browser's local storage. The attack surface is small, but reports are still welcome.

## Supported versions

Only the latest build is supported: the [hosted game](https://iron0037.github.io/after-waking/), built from `main`.

## Reporting a vulnerability

Please report it privately, not in a public issue. Use the repository's **Security** tab, then **Report a vulnerability**, to open a private advisory.

Please include the steps to reproduce it and what an attacker could do with it. For example, a crafted save file that runs script when it's imported would be a security problem.

You can expect a reply within a week. Fixes ship as soon as they're ready, and with your permission, you'll be credited in the commit.
